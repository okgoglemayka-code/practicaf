## 🔬 Методы анализа

В проекте реализован **комбинированный метод**, объединяющий 4 подхода. Каждый метод расположен в отдельной функции файла `analysis/classifier.py`.

---

### Метод 1. Словарный поиск

| Свойство | Значение |
|----------|----------|
| **Файл** | `analysis/classifier.py` |
| **Функция** | `_keyword_search()` |
| **Суть** | Прямой поиск заранее составленных слов-маркеров |

**Локация в коде:**
```python
# analysis/classifier.py, строки 70-95
KEYWORDS = {
    'extremism': ['экстремизм', 'террор', 'джихад', ...],
    'suicide': ['самоубийство', 'суицид', 'не хочу жить', ...],
    'aggression': ['убить', 'смерть', 'насилие', ...],
    'hate_speech': ['жиды', 'хачи', 'чурки', ...],
    ...
}
```

**Что делает:**
- Приводит текст к нижнему регистру
- Ищет совпадения с ключевыми словами
- Возвращает категорию + уровень критичности

---

### Метод 2. Тональностный анализ

| Свойство | Значение |
|----------|----------|
| **Файл** | `analysis/classifier.py` |
| **Функция** | `_analyze_sentiment()` |
| **Библиотека** | `dostoevsky` (FastTextSocialNetworkModel) |
| **Суть** | Определение эмоциональной окраски текста (негатив/позитив/нейтрально) |

**Локация в коде:**
```python
# analysis/classifier.py, строки 97-115
def _analyze_sentiment(self, text: str) -> Dict:
    result = self.sentiment_model.predict([text[:500]])[0]
    return {
        'negative': result.get('negative', 0.0),
        'positive': result.get('positive', 0.0),
        'neutral': result.get('neutral', 0.0)
    }
```

**Что делает:**
- Загружает предобученную нейросетевую модель
- Анализирует эмоциональную окраску
- Возвращает вероятности негатива, позитива, нейтральности

---

### Метод 3. Статистический анализ

| Свойство | Значение |
|----------|----------|
| **Файл** | `analysis/classifier.py` |
| **Функция** | `_text_statistics()` |
| **Суть** | Анализ формальных признаков текста |

**Локация в коде:**
```python
# analysis/classifier.py, строки 117-135
def _text_statistics(self, text: str) -> Dict:
    stats = {
        'length': len(text),
        'exclamation_count': text.count('!'),
        'caps_ratio': caps_letters / total_letters,
        'has_rage_caps': caps_ratio > 0.3  # капс-ярость
    }
```

**Что делает:**
- Подсчитывает длину текста
- Считает количество восклицаний (`!`) и вопросов (`?`)
- Вычисляет долю заглавных букв
- Определяет **капс-ярость** (>30% заглавных)

---

### Метод 4. Интеграция решений

| Свойство | Значение |
|----------|----------|
| **Файл** | `analysis/classifier.py` |
| **Функция** | `classify()` |
| **Суть** | Объединение результатов трёх методов с приоритетными правилами |

**Локация в коде:**
```python
# analysis/classifier.py, строки 137-195
def classify(self, text: str) -> ClassificationResult:
    # 1. Словарный поиск
    keyword_category, matched_words, keyword_level = self._keyword_search(text)
    
    # 2. Тональность
    sentiment = self._analyze_sentiment(text)
    
    # 3. Статистика
    stats = self._text_statistics(text)
    
    # 4. Приоритетные правила
    if keyword_category in [EXTREMISM, SUICIDE]:
        return HIGH
    if keyword_category:
        confidence = 0.6 + neg_score * 0.3
        if stats['has_rage_caps']:
            confidence += 0.1
        return (keyword_category, keyword_level, confidence)
    if neg_score > 0.75:
        return (NEGATIVE, LOW, neg_score)
    return (SAFE, 0, 1 - neg_score)
```

**Алгоритм приоритетов:**
```
1. Экстремизм / Суицид → 🔴 HIGH (уровень 3)
2. Агрессия / Язык вражды → 🟠 MEDIUM (уровень 2)
3. Сильный негатив без маркеров → 🟡 LOW (уровень 1)
4. Всё остальное → ⚪ SAFE (уровень 0)
```

## 📊 Итоговые категории

| Категория | Уровень | Описание | Пример |
|-----------|---------|----------|--------|
| `extremism` | 3 (HIGH) | Призывы к экстремизму, террору | "пора взрывать" |
| `suicide` | 3 (HIGH) | Пропаганда суицида | "не хочу жить" |
| `aggression` | 2 (MEDIUM) | Агрессия, насилие | "я тебя убью" |
| `hate_speech` | 2 (MEDIUM) | Язык вражды | "ненавижу этих..." |
| `misinformation` | 1 (LOW) | Дезинформация | "очередной фейк" |
| `manipulation` | 1 (LOW) | Манипуляция | "шок! срочно!" |
| `negative` | 1 (LOW) | Сильный негатив | "всё ужасно" |
| `safe` | 0 (NONE) | Безопасно | "хороший день" |
