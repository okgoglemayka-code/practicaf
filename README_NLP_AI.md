# NLP/ИИ-модуль для улучшения классификации

Добавлен файл `analysis/nlp_ai.py` и обновлён `analysis/classifier.py`.

## Как включить

1. Установить Ollama.
2. Скачать модель:

```bash
ollama pull qwen2.5:7b-instruct
```

3. В `config.py` поставить:

```python
ENABLE_NLP_AI = True
```

## Как работает

Основная scoring-модель остаётся первой. AI вызывается только для спорных случаев:
- score от 2 до 6;
- низкая уверенность;
- потенциально опасные категории.

Если AI недоступен, проект продолжает работать без ошибки.
